# FEAST MODE® — Case Study

Portfolio case study for [FEAST MODE®](https://feast-mode-eta.vercel.app), a scroll-driven landing page for a fictional food brand, built 4–6 November 2026.

- **Design, art direction, references and QA:** Anita (UX/UI designer)
- **Build, image generation and testing:** Claude, with images generated in Higgsfield
- **Landing page code:** [AnitaLever-UX/feast-mode](https://github.com/AnitaLever-UX/feast-mode)

Static HTML, CSS and JavaScript with no build step. GSAP 3.12.5 and ScrollTrigger are bundled in `js/`.
All screenshots are captures of the deployed landing page; the before images in chapter 08 are Anita's own device screenshots.

To save a PDF version, open the page in a browser and use Print → Save as PDF; the print layout shows every scene's frames.
